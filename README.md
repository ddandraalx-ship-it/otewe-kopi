# Otewe Kopi — Modern Aesthetic Web Application

Website resmi **Otewe Kopi** Taman Apsari Surabaya.

- **Stack**: Laravel 11, Tailwind CSS, Alpine.js
- **Design System**: Warm Mocha Experience (`#C08452` & `#0F0D0B`)
- **Features**: Responsive Swipable Category Tabs, Section Watermark Anchors, Live Band & Reservation Info

Deployed with Vercel Serverless PHP.
